### 🧠 Visual Field Test Features

2. Implement the **24-2 Grid (54 test points)**:
   - Use ±24° layout with 54 points (24-2 standard).
   - Show a central fixation cross at all times.

3. **Stimulus Presentation**:
   - Stimuli should be Goldmann Size III (0.43°).
   - Stimulus should appear for **500ms**.
   - Show white stimulus on gray background.
   - Accept response if screen is tapped **within 50–1500 ms** of stimulus onset.
   - Hide stimulus after 500 ms.

4. **4–2 Staircase Logic**:
   - Start at 24 dB.
   - If seen, decrease intensity by 4 dB.
   - If missed, increase by 4 dB.
   - Once bracketed, switch to ±2 dB until threshold is found.
   - Continue until each point has a final threshold value.

5. **Breaks**:
   - If the user pauses or reloads, test should resume where left off.

### 📊 Reliability Indices (Calculate in backend):

7. Reliability metrics:
   - False Positives (FP): patient taps when **no stimulus** is shown
   - False Negatives (FN): patient fails to respond to **bright stimulus at seen point**
   - Fixation Loss (FL): stimulus at blind spot is tapped
   - Show all 3 values with alerts if:
     - FP > 15%
     - FN > 25%
     - FL > 20%
